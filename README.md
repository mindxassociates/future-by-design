# Future by Design — Interactive Client Guide

A self-contained, accessible learning experience for building clarity, protecting attention, testing new directions, and making meaningful progress over time. Open `index.html` in any modern browser. No server, account, internet connection, or build step is required.

## Features

- 10 concise modules plus a three-traits synthesis
- interactive reflection prompts and decision tools
- progress tracking saved only in the visitor's browser
- searchable key-point library
- flashcards and a knowledge check
- print-friendly personal action plan

The material is designed for personal reflection, coaching, and educational use.
